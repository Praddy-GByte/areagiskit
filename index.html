AreaGIS KitBETA

One area. Six studies. 236 analyses.

Pick an area in QGIS or ArcGIS Pro, choose a study and press Run. AreaGIS Kit fetches the open data for your area, runs the full study, compares its results with independent data where it exists, grades its confidence and writes the report in Word, PDF and HTML, including what the results cannot tell you.

How it works

The methods are established, published ones. AreaGIS Kit puts a whole study into one reproducible run.

1 · Area

Choose your area

A polygon layer, the map extent, or a drawn box. Health uses your own area polygons and case counts.

2 · Data

Data comes to you

Sentinel-1/2, Landsat, MODIS, Copernicus DEM, GHSL, OpenStreetMap and more, fetched for your area only. No account, no manual download.

3 · Study

The full study runs

Every standard analysis for the field, from the event map to models, trends, hot spots and impact.

4 · Report

Checked and written up

Results compared with independent data where it exists, a confidence grade, and a complete report with maps, tables and limits.

Install

Free and open source. Pick the platform you use.

  1. Download areagiskit.zip from Releases (do not unzip it).
  2. In QGIS 3.28 or newer: Plugins › Manage and Install Plugins › Install from ZIP, choose the file, Install Plugin.
  3. The studies appear under the AreaGIS Kit toolbar button and in the Processing Toolbox › AreaGIS Kit.
The plugin is waiting for approval on the official QGIS Plugin Repository. Once approved you can also install it by searching “AreaGIS Kit” in the Plugin Manager (tick “Show also experimental plugins”). Single-study zips (areagiskit_flood.zip and others) are on the Releases page for anyone who wants only one.
  1. Download AreaGIS_Kit_for_ArcGIS_Pro.zip from Releases or ArcGIS Online, and unzip it. Keep AreaGIS Kit.pyt next to the areagiskit folder.
  2. In ArcGIS Pro: Catalog › Toolboxes › Add Toolbox › AreaGIS Kit.pyt.
  3. Open a tool, choose an area (polygon layer or extent), set the options and an output folder, Run. Result layers are added to the active map.
The tools need GDAL’s Python package. If a tool shows a GDAL warning: Project › Package Manager › Environment Manager › clone arcgispro-py3 › activate the clone › Add Packages › gdal › restart ArcGIS Pro. The ArcGIS Pro version is new and in beta: please report anything that does not work.

The engine runs without QGIS or ArcGIS. It needs GDAL’s Python bindings; conda is the easiest way:

conda create -n areagis -c conda-forge python=3.12 gdal numpy matplotlib scipy
conda activate areagis
pip install areagiskit
areagiskit list

If GDAL is already installed (for example the Python inside QGIS, or apt install python3-gdal), pip install areagiskit is enough.

Use

Every study follows the same four steps.

In QGIS or ArcGIS Pro

  • Open the study (toolbar button, Processing Toolbox or ArcGIS toolbox).
  • Choose the area: a polygon layer, the map extent or a drawn box.
  • Set one or two options; every option has a sensible default.
  • Press Run. The report opens when it is finished and the result layers are added to the map.

From Python

from areagiskit.core.aoi import AOI
from areagiskit.kits import get

area = AOI(bbox=[67.6, 26.6, 67.9, 26.85], name="Dadu")
kit = get("floodstudy")()
result = kit.run(area, {"event_date": "2022-09-03"}, "out/dadu")

print(result["summary"])
print(result["verdict"]["level"])   # High / Medium / Low
print(result["report"])             # report.html, .docx, .pdf

Studies: floodstudy, lulc, landslide, cropstudy, urbanstudy, healthstudy. Run areagiskit list to see every option.

From the command line

areagiskit floodstudy --bbox 67.6 26.6 67.9 26.85 \
  --name "Dadu, Sindh" event_date=2022-09-03 --out out/

areagiskit landslide --bbox 76.08 11.43 76.22 11.56 \
  --name "Wayanad" event_date=2024-07-30 --out out/

areagiskit healthstudy areas=wards.gpkg id_field=ward_id \
  cases_field=cases population_field=pop --out out/
An internet connection is needed while a study runs, because the data is fetched for your area at that moment. Each report ends with the exact command to reproduce its numbers.

  • Random Forest model

  • Multicollinearity check (VIF)

Hazard & risk

  • Hazard map (depth × duration)
  • Risk map (hazard × exposure)
  • Vulnerability index incl. poverty (RWI)
  • Risk with vulnerability
  • Flood hot spots (Gi*)
  • Encroachment into flood zones 1990–2020
  • Exposure in 10/100/500-year zones (GloFAS)
  • 10- and 100-year flood depth (HAND model)
  • River-flow forecast, ~7 months ahead
  • Hidden flood under trees, crops and buildings
  • Radar before/after composite

Response

  • Nearest safe high ground for each settlement
  • Evacuation distance and direction (road distance with OSM)
  • What-to-do priorities and warning flow levels

Validation

  • 30% hold-out AUC
  • Temporal test (old floods → new floods)
  • AUC against GloFAS flood model
  • Independent re-detection from raw radar
  • Sentinel-2 optical check
  • Copernicus EMS expert maps, found and compared automatically
  • Your observed flood polygon (CSI, F1) with your data
  • Statistics for your zones with your data
What this study will not tell you
  • The exact water depth at a house: depth comes from a 30 m elevation model whose vertical error (2–4 m) can be larger than the water depth.
  • A safe evacuation route: "safe high ground" is a straight-line distance and direction, not a checked route. Follow official evacuation plans.
  • When the next flood will come: the river-flow forecast is the GloFAS model at one river cell with no local skill score; after 2–4 weeks it is only an outlook.
  • Losses you can rely on: damage curves are continental averages (JRC), not calibrated for this area; money appears only if you give asset values.
  • Engineering flood lines: 10/100-year zones come from global models and a simple terrain model, for screening only.
  • Water the radar cannot see: under dense trees, between tall buildings, and very short floods between satellite passes.
  • An independent accuracy for susceptibility: the hold-out AUC is optimistic because the flood inventory comes from the same satellite record.

Physics

Runout

  • Debris runout zones (Flow-R)
  • Debris speed along the path
  • People, houses and roads in runout

Risk

  • Risk classes (susceptibility × exposure)
  • Landslide hot spots (Gi*)
  • Settlements at risk
  • Observed landslide frequency per class (short record)
  • Field check points
  • What-to-do guidance
What this study will not tell you
  • Whether a particular slope will fail: the factor of safety uses textbook soil strengths from global soil maps, not site tests. "Unstable" means relatively weakest, not "will fall".
  • When the next landslide will happen: timing needs rainfall warnings. The 1/10/50-year chances come from only a few years of satellite record.
  • Exact debris reach and speed: runout uses general parameters (11° travel angle, speed capped at 15 m/s), not values calibrated for this region.
  • Landslides smaller than about 20 m, under forest canopy, or slow-moving ground (that needs InSAR, which needs an account).
  • The rain that triggered a landslide on a slope: rainfall comes from ~50 km cells and can miss mountain downpours by several times (Wayanad 2024: 88 mm in the cell vs 573 mm at a gauge 5 km away).
  • An independent accuracy, unless you supply an inventory: automatic AUCs are optimistic because training and test scars come from the same detection.

  • Air temperature in a street: hourly air temperature, heat index, WBGT and UTCI come from ~50 km NASA POWER cells, so the whole city gets one or two values.

  • Individual trees or buildings: the data are 10–100 m.

  • Data and method: every dataset with resolution, dates and licence
  • Print-ready maps with north arrow, scale bar, legend, grid and location inset
  • Results, charts and tables for every analysis

  • CSV tables for every chart and table in the report
  • Layers added to your QGIS project or ArcGIS Pro map automatically

Confidence grade

Every report tells you how far to trust it.

Where independent data exists, the study compares its own results with it: expert flood maps, published land cover maps, a real event the model did not see, reported statistics and so on. The grade is built from those checks:

HighMediumLow
  • Checks that are not truly independent (for example, a model tested on labels from the same source) are labelled as such and weigh less.
  • If a method does not work for an area, the report says so and the grade goes down. Results that fail their check are not presented as reliable.
  • The grade describes this run on this area. It is not a guarantee: always look at the maps and check against what you know.

FAQ

Do I need an account or an API key?

No. Every data source is open and is read without logging in.

Does it work anywhere in the world?

Yes, the data sources are global. A few checks use regional reference data (for example, US crop statistics); where that is missing the report says so and the confidence grade reflects it.

How big can my area be?

Up to 3,000 km² for Flood and 1,500 km² for LULC, Landslide, Crop and Urban. Health works with your own area polygons up to 200,000 km². Start small: a district or a city is a good first run.

How long does a study take?

From about 4 minutes (Health) to about 25 minutes (Landslide) for a typical area, depending on the area size and your internet connection.

Can I use my own data?

Yes. Many analyses get better with your input: field points with crop names, a landslide inventory, your boundaries, facilities, asset values, case data. They are marked “with your data” in the study lists.

Is it free for commercial work?

The code is GPL-3.0-or-later. Most data is open for any use with credit, but a few sources (Meta Relative Wealth Index, GEM seismic hazard, Open-Meteo’s free API) are non-commercial only. Check DATA_LICENSES.md before paid work.

Something did not work. What should I send?

Open an issue with the study name, the message shown (a screenshot is perfect), the area, and your QGIS or ArcGIS Pro version and operating system.
